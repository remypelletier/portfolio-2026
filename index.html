SplashMap - tout le lavage auto, sur une seule carte

En collaboration avec un designer, j'ai réalisé toute la partie technique : données, recherche cartographique avec filtres, contributions communautaires, sécurité, SEO, RGPD et mise en production.

  • Recherche géographique centralisée via une RPC PostGIS
  • Système de contributions communautaires : avis, signalements, nouveaux points
  • Sécurité : politiques RLS et limitation des requêtes API
  • Tests Vitest sur les fonctionnalités clés, CI/CD GitHub Actions et déploiement sur Vercel

Le défi : constituer puis fiabiliser un référentiel national. Une extension Chrome dédiée accélère la vérification des équipements, station par station.
